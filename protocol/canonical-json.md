# Canonical JSON and the release digest

A release is identified by `releaseDigest = "sha256:" + hex(SHA-256(UTF-8(canonical(pins))))`.
Two runtimes in two languages must produce the same digest from the same
pins, or a runtime would refuse a manifest the console sealed. The encoding
is therefore pinned here, not left to a language's default serializer.

## Rules

1. **Object members are sorted by key**, comparing UTF-16 code units. In
   JavaScript that is the default `Array.prototype.sort` on strings; in
   Python, `sorted(keys, key=lambda k: k.encode("utf-16-be"))` (which, for
   keys without astral characters, is plain `sorted(keys)`).
2. **No whitespace** anywhere.
3. **Strings** are escaped exactly as `JSON.stringify` does: `"`, `\`, and
   the control characters U+0000–U+001F (as `\b \f \n \r \t`, else
   `\u00XX`). Every other code point — non-ASCII, U+2028, U+2029, emoji —
   is emitted raw and encoded as UTF-8.
4. **Numbers** must be finite integers in the safe range (|n| ≤ 2⁵³ − 1)
   and are written without a fraction or exponent; `-0` is written `0`.
   Non-integers are refused: a release never needs one, and float
   formatting is where languages disagree.
5. `null`, `true`, `false` as in JSON. Undefined values, functions,
   symbols, BigInt, dates and class instances are **refused**, never
   silently dropped.

## The digest input

Only the pins, sorted by `tag`, each projected to exactly these members:

```
tag, kind, artifactId, versionId, versionOrdinal (integer or null),
contentHash, byteLength, model, variables[{ name, required, trust }]
```

Nothing else in a release — who sealed it, when, warnings, acks,
countersignatures — is covered by the digest. Anything that must be
verifiable on the runtime is a pin member; anything mutable is not.

## Vectors

`vectors/canonical-json.json` carries cases generated by an independent
encoder (Python `json.dumps(v, sort_keys=True, separators=(",", ":"),
ensure_ascii=False)`), each with the canonical text and its SHA-256.
The hosted service's TypeScript encoder is tested against the same file.
An SDK passes when, for every vector, its canonical text and digest match.
The `refused` list names inputs that must raise rather than encode.
