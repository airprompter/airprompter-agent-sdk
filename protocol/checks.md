# Declared output checks (5-E)

A slot may declare **output checks**: deterministic tests the runtime runs
on the host, on the model output the SDK already sees, after every call it
observes. Nothing of the output leaves the process; the window row carries
two counters, `checks.passed` and `checks.failed`, and the console reads
them per arm as a guardrail ("output checks failed never worse"). Checks
measure **form, not quality** — an answer can pass every check and be
wrong — and every console surface says so.

Reference: `conformance/checks.mjs`. Vectors: `vectors/checks.json`
(generated by `tools/gen_check_vectors.mjs`). Both SDKs pass them.

## Kinds

| Kind | Members | Passes when |
| --- | --- | --- |
| `json_schema` | `schema` (≤ 16 KiB) | the output parses as JSON — the whole text, or the first `{`/`[` to the last `}`/`]` for a fenced or prefixed block — and validates against the subset below |
| `enum` | `path` (dotted, ≤ 128 chars; `""` = the whole trimmed output), `values` (1–64 strings) | the string at `path` in the parsed JSON is one of `values`; with `path: ""`, the trimmed output (a bare JSON string counts as its value) |
| `length` | `minTokens` and/or `maxTokens` (0–1,000,000, min ≤ max) | the output's tokens lie in the band — the provider's reported output count when `observe()` saw one, else `ceil(UTF-8 bytes / 4)` |
| `must_match` | `pattern` (≤ 256 chars), optional `flags: "i"` | the pattern occurs in the output |
| `must_not_match` | same | the pattern does not occur |

Every check has a `name` (`^[a-z0-9]+(?:[._-][a-z0-9]+)*$`, ≤ 64) unique
on the slot; a slot carries at most 8. In the console a check also has
`enabled`; the pin and the manifest carry **enabled checks only, sorted by
name, with only the kind's own members** (`projectChecks`), and that list
is part of the release digest input when present (canonical-json.md) — a
changed check is a new release, which is how it reaches the fleet.

Failure reasons (per check, never on the wire): `not_json`,
`schema_mismatch`, `path_missing`, `not_a_string`, `not_in_enum`,
`too_short`, `too_long`, `no_match`, `matched`, `subject_too_long`,
`pattern_refused`, `unknown_kind`.

## The JSON Schema subset

`type` (a name or a list; `integer` satisfies `number`), `enum`, `const`,
`properties`, `required`, `additionalProperties: false`, `items`,
`minItems`, `maxItems`, `minLength`, `maxLength` (code points), `minimum`,
`maximum`, `pattern` (the regex rule below applies), `anyOf`. Any other
keyword is ignored, so a schema never fails on what the evaluator does not
know. `$ref` is not supported.

## The regex safety rule

Patterns run on untrusted model output, so a pattern that can backtrack
catastrophically is refused at declaration and fails closed at evaluation:

* **RE2-class syntax only** — no backreferences (`\1`, `\k<n>`), no
  lookaround (`(?=`, `(?!`, `(?<=`, `(?<!`), no atomic or possessive groups
  (`(?>`, `a++`, `a*+`, `a?+`), and no quantified group whose body is itself
  quantified (`(a+)+`, `(a*)*`, `(x{2,})+`, `((ab)*c)+`).
* Only `{n}`, `{n,}` and `{n,m}` are counted quantifiers; a bare `{` or `}`
  is `invalid` (escape it).
* At most 256 characters; `flags` is `"i"` or absent.
* **Subject cap**: an output over 64 KiB fails the check closed
  (`subject_too_long`) — never a partial scan that could hide forbidden
  text.

Portability: patterns are compiled with Unicode-aware (`u`) semantics in
JavaScript and ASCII character classes in Python (`\d`, `\w` match ASCII in
both); avoid `\p{…}` and `\s` on non-ASCII whitespace, and note that
Python's `$` also matches before a trailing newline. The vectors stay
within the portable core.

## Where the counts go

`checks.passed` / `checks.failed` on the window row of the run that was
observed (spool-format.md), one increment per check evaluated. An app that
calls the model itself may run `ap.checks(rendered, output)` and the counts
land on the same window without adding a run. A failing check never
throws in the request path: it counts. Render guards (refusing to serve on
a failed check) are not part of this document.
